# ELEC2645 Unit 1.3: Functions and Modular Code

This repository contains six C programming activities in one folder. Work through them in order, following the guidance in each activity's Markdown file and editing the corresponding source files.

## Activities

1. [Function Prototypes](activity1_function_prototypes.md)
2. [Using Libraries](activity2_using_libraries.md)
3. [Value vs Reference](activity3_value_reference.md)
4. [Structs](activity4_structs.md)
5. [Reading and Writing Files](activity5_files.md)
6. [Debug Practice](activity6_debug_practice.md)

The [ELEC2645 reference guide](https://eee-elec2645.github.io/) contains further explanations and examples. Use its search box if you need help with a topic.

## Testing your work

```text
make test1    Activity 1: Function Prototypes
make test2    Activity 2: Using Libraries
make test3    Activity 3: Value vs Reference
make test4    Activity 4: Structs
make test5    Activity 5: Reading and Writing Files
make test6    Activity 6: Debug Practice
```

Running `make test` displays the same list. A failed build or test is normal while you are working. Read the compiler messages and feedback from `d[o_0]b ELEC2645 Bot`, update your code and try again.

Run `make clean` to remove compiled `.out` files.

## Optional: Run and Debug

The repository includes VS Code Tasks and Run and Debug configurations for every activity. See [DEBUGGING.md](DEBUGGING.md) for a short introduction.
